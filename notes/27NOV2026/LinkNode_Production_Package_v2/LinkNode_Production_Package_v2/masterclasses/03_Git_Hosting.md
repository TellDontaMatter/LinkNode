# Masterclass: Git Hosting Video — 8-12 min
**Format:** 16:9, 8-15 min, Teleprompter-ready
**Face Rule:** FULL HOST PRESENCE — On-camera hook, screen walkthrough, on-camera closer
**Voice:** Calm, razor-sharp, zero hyperbole, developer-first
**Script / Structure:**
HOOK (HOST ON CAMERA): 'Pages failed? Good. That means you pushed.' [pause] ACT 1: Branch check — main vs master. ACT 2: Push — git push -u origin main, auth, errors. ACT 3: Pages settings — source, folder, build. ACT 4: Verify live graph — index.html + graph.json paths. CLOSER (HOST ON CAMERA): 'If it loads local, it loads live.' [1.5s pause]
**Production Notes:** [bracketed production notes for ElevenLabs pacing throughout] — [1.5s pause] after code, [pause] after hook, [beat] before closer.
**Thumbnail Rule:** Face ALLOWED — Host face + bold text + graph.
